## 3. Step-by-Step Operator Workflow

1. **Author MVS Inputs**: Drop sparse requirements or schemas into `user/inputs/templates/`.
2. **Trigger Autonomous Derivation**: Percipience infers configs, wire contracts, and code skeletons into `workplace/`.
3. **Ephemeral Worktree Isolation**: Subagents lease isolated sandboxes (`.workspaces/subagent_*`) with Tree-Sitter AST token pruning.
4. **Independent Verification Gates**: Run AST schema validation, test coverage audits, and contract compatibility checks.
5. **Seal Merkle State Block**: Compute SHA-256 block hash, append to `context_ledger.yaml`, and record recovery snapshot.
6. **Maturity Scorecard**: Emit `context_maturity_report.md` with multi-dimensional evaluation metrics.
